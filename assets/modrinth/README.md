# Modrinth artwork

Bundled UI artwork used only by the Modrinth-inspired shell:

- `instance-icons/*.png` — default instance icons from
  `refs/modrinth/apps/app-frontend/src/assets/instance-icons/`.
- `branding/wordmark.png` — the Modrinth text logo extracted from
  `packages/ui/src/components/brand/TextLogo.vue` and rasterised on the
  titlebar surface colour.
- `branding/modrinth-icon.png` — Modrinth App icon from
  `refs/modrinth/apps/app/icons/128x128.png`.
- `skins/steve.png` — default Steve skin from
  `refs/modrinth/apps/app-frontend/src/assets/skins/steve.png`.

Source: Modrinth App (Theseus), Modrinth / Theseus contributors,
GPL-3.0, <https://github.com/modrinth/code>. The launcher credits this
project in `crates/amc-ui/src/shells/modrinth.rs`.
