*Часть экосистемы Aleph Trust. Технологии: Rust + Egui + wgpu. Целевое железо — вплоть до GT710, Windows 7 или Linux.*

## Лицензирование
- Модель распространения (опенсорс/закрытый) пока не определена окончательно.

## Монетизация
- Никакой рекламы нигде в лаунчере (в отличие от TLauncher).
- Донаты/поддержка разработчиков — как способ монетизации, но все функции лаунчера остаются бесплатными.

## Первый запуск: мастер настройки
Порядок шагов при первом запуске:

1. **Выбор языка интерфейса** (автоопределяется по системе, можно сразу поменять).
2. **Выбор привычного лаунчера** — какой существующий лаунчер пользователю ближе всего:
   - **Простые** (Legacy, TLauncher и подобные) — минимальный набор функций.
   - **Продвинутые** (MultiMC, Modrinth App) — расширенный функционал.

   От этого выбора зависит интерфейс и частично доступный функционал. Настройку можно изменить позже в любой момент.
3. **Предложение входа в аккаунт** (см. раздел «Аккаунты»). Вход/регистрация WetID открывается через браузер (внешняя страница), не встроенной формой.

Мастер обязателен для всех — пропустить его и сразу попасть в профессиональный режим с дефолтами нельзя. При первом запуске также есть обучающий тур/подсказки для новичков.

При первом запуске также выполняется встроенный тест скорости/совместимости железа (учитывая целевой минимум — уровень GT710). Тест можно повторить вручную в любой момент позже, не только при первой настройке. Если железо слабее — лаунчер предлагает облегчённые настройки/режим (но не блокирует). Тест железа не влияет на выбор упрощённого/профессионального режима из шага 2 — режим выбирает только сам пользователь, это независимые вещи.

Если на ПК уже есть папка .minecraft от другого лаунчера, AMC предлагает скопировать уже скачанные файлы вместо повторной загрузки (экономия трафика и времени).

Между упрощённым и профессиональным режимом можно свободно переключаться в любой момент из настроек.

## Режимы работы

### Упрощённый режим
- Только одна активная настройка за раз (не несколько параллельных — для этого есть профессиональный режим).
- Выбор версии Minecraft, включая snapshot/pre-release, а также старые alpha/beta/classic версии (актуально для стиля Legacy).
- Кнопка «быстрый старт» — мгновенный запуск ванильной игры для новичков, версия — последняя использованная пользователем (не всегда самая свежая релизная).
- Докачка модов прямо из лаунчера через Modrinth или CurseForge.
- Поиск и установка отдельных модов, не только готовых сборок целиком.
- Автоподсказка актуальной версии загрузчика модов (Forge/Fabric/и т.д.), если требуется.
- Обновление всей сборки модов одной кнопкой.
- Портирование сборки на другую версию Minecraft.

### Профессиональный режим
- Создание нескольких независимых сборок (инстансов), по аналогии с MultiMC / Prism Launcher.
- Готовые шаблоны для быстрого старта (vanilla+, optimized и т.д.), помимо пустой сборки — только от команды AMC, без пользовательских/сообщественных шаблонов в v1.0.
- Кастомизация сборок: своя иконка (загрузка картинки или выбор из готового набора) и название для каждой.
- Клонирование (дублирование) существующей сборки — при клонировании можно выбрать, копировать ли миры/сейвы или только моды/настройки.
- Организация большого числа сборок через папки/теги, сортировку (по дате/имени/времени игры), закрепление избранных сборок сверху списка и быстрый поиск по названию.
- Личные заметки к сборке (сид, с кем играем и т.д.).
- Pre-launch/post-exit скрипты — свои команды до/после запуска сборки, для продвинутых пользователей.
- Несколько сборок можно связать в группу с общими настройками Java/RAM — изменение применяется сразу ко всей группе.

## Карточка сборки
- Без клика видно: иконка, название, версия Minecraft, загрузчик, время в игре, дата последнего запуска.

## Поиск модов/сборок: рейтинги
- В результатах поиска показываются рейтинги/отзывы, подтянутые с Modrinth/CurseForge.

## Главный экран
- Разные экраны для упрощённого и профессионального режима (не единый универсальный интерфейс).

## Установка перетаскиванием
- Мод или целую сборку можно установить drag-and-drop файла в окно лаунчера.
- Готовый мир (сейв) можно импортировать в сборку перетаскиванием папки.

## Офлайн-режим
- После первого запуска можно играть офлайн (без интернета).

## Загрузчики модов
- Поддержка всех существующих загрузчиков (Forge, Fabric, Quilt, NeoForge и др.) с автоопределением нужного при установке модов/сборки.
- OptiFine обрабатывается как обычный мод, а не отдельный загрузчик. Статус кода: в текущей разработке OptiFine временно доступен выбором загрузчика (быстрый путь P2); в P4 он переезжает в установку модом на совместимую сборку.
- Перед установкой мода лаунчер проверяет и показывает совместимость с текущей версией Minecraft/загрузчика.
- При создании сборки со старым/небезопасным загрузчиком (например, старый Forge с известными уязвимостями) лаунчер предупреждает об этом.
- Поиск модов/сборок с фильтрами: категория, популярность, версия Minecraft.
- Моды/ресурспаки можно добавлять в личный вишлист/избранное (общий для всех сборок) без немедленной установки.
- Можно выделить несколько модов сразу и обновить/удалить их одним batch-действием.
- Скачанные файлы проверяются на целостность по хеш-суммам.
- Если мод требует другой мод как зависимость, лаунчер автоматически ставит зависимость.
- Если два установленных мода известны как несовместимые друг с другом, лаунчер предупреждает об этом до запуска.
- При установке мода предлагаются похожие/совместимые моды («с этим часто ставят»).

## CLI-режим
- Нужен режим без графического интерфейса (CLI) для автоматизации и использования на серверах.

## Билды лаунчера
- Debug и release билды в коде (единый релизный канал для пользователей, без отдельных stable/beta).

## Источники модов
- Встроенные источники: только Modrinth и CurseForge. Также можно загрузить внешний/локальный мод-файл вручную. Поддержки своих репозиториев/сайтов нет.
- Проверки безопасности (антивирус-скан) для вручную загруженных локальных модов нет — пользователь отвечает за это сам.
- Сборки с локальными (не-маркетплейс) модами получают визуальную пометку/значок в профессиональном режиме — уже в v1.0, заранее готовясь к ограничению доступа на Aleph Trust сервера в 2.0.

## Хранение на диске
- Можно выбрать, где хранить сборки/моды (например, на другом диске).

## Хранение сборок
- Дедупликации общих файлов (assets/библиотек) между сборками нет — каждая сборка полностью отдельная и самодостаточная.

## Логи и консоль
- Встроенный просмотр логов/консоли игры прямо в лаунчере.
- Кнопка скопировать/загрузить лог — для быстрой отправки в поддержку или друзьям.

## Ярлыки и запуск
- Можно создать ярлык на рабочем столе/в меню «Пуск» для быстрого запуска конкретной сборки без открытия лаунчера.
- На ноутбуках с двумя GPU (встроенная + дискретная) можно выбрать, на какой видеокарте запускать сборку.
- Разрешение и оконный/полноэкранный режим настраиваются из лаунчера отдельно для каждой сборки.
- Пока игра запущена, в панели задач/трее отображается иконка самой сборки, а не стандартная иконка Minecraft.

## Редактор конфигов
- В профессиональном режиме есть встроенный редактор config-файлов модов.

## Место на диске
- Показ занятого места на диске по каждой сборке/папке.
- Перед скачиванием большой сборки лаунчер проверяет свободное место и предупреждает, если его не хватает.

## Управление Java
- Гибридная модель: лаунчер сам скачивает и переключает нужную версию Java автоматически, но у пользователя остаётся ручная опция настройки.
- Отдельный экран-менеджер Java со списком всех установленных/скачанных версий (добавить/удалить).
- Если Java уже установлена в системе — лаунчер её находит (в том числе по известным местам других лаунчеров, без полного импорта их профилей) и предлагает использовать вместо скачивания своей.

## Моды, требуемые сервером
- Если сервер требует определённые моды, при подключении появляется окно со списком нужных модов и кнопкой автоматической установки — лаунчер сам доустанавливает их из доверенных источников.

## Список серверов (server browser)
- В v1.0 не реализуется. Есть сомнения, нужен ли он вообще — воспринимается скорее как рекламный инструмент, а не полезная функция (игроки обычно уже знают, куда хотят играть).
- Без общего браузера всё же можно сохранить свой сервер в избранное/быстрый доступ.
- Сервер, добавленный в избранное в лаунчере, автоматически появляется в списке серверов каждой сборки — не нужно вручную добавлять его в игре. Отдельной кнопки «играть» на избранный сервер в самом лаунчере нет — сервер просто заранее прописан в игровом меню мультиплеера.
- Онлайн-статус и пинг избранного сервера видны прямо в лаунчере, без захода в игру, включая список игроков онлайн.

## Автозапуск
- Лаунчер можно настроить на автозапуск вместе с ОС.

## Поддерживаемые ОС
- Windows и Linux (macOS не в приоритете для v1.0).
- Установщик на Windows проверяет наличие нужных системных компонентов (.NET/VC++ и т.д.) и ставит недостающие.

## Ресурспаки и шейдеры
- Встроенный поиск и управление прямо из лаунчера (аналогично модам).
- Менеджер ресурспаков показывает превью картинок текстур.
- Фильтр поиска по разрешению текстур (16x/32x/64x и т.д.).
- Приоритет между несколькими ресурспаками не настраивается перетаскиванием в лаунчере — только стандартным/ручным способом в файлах.
- Установка шейдера не проверяет совместимость с OptiFine/Iris — ставится без предупреждения о возможном конфликте.

## Автообновление лаунчера
- Лаунчер обновляется автоматически сам по себе.
- Проверка обновлений происходит только при запуске лаунчера, не периодически во время работы.
- После обновления показывается попап с changelog («что нового»).
- Перед установкой обновления проверяется его цифровая подпись (защита от подмены).
- Подсказки на случай ложного срабатывания антивируса на файлы лаунчера/модов нет — это вне зоны ответственности лаунчера.
- Откатиться на предыдущую версию самого лаунчера можно (лаунчер опенсорс), но старая версия не будет поддерживать «доверенный режим запуска». Этот режим нужен только для входа на Aleph Trust сервера — на обычных серверах и оффлайн старая версия работает без проблем. Обновление обязательно только тогда, когда нужно зайти именно на Aleph Trust сервера.
- «Доверенный режим» доступен только официальным подписанным сборкам от AMC — включая портативную версию и Linux-сборки, не только Windows-установщик. Самостоятельно собранная (self-compiled) версия из исходников работает как обычный лаунчер для всего, кроме входа на Aleph Trust сервера.
- Единый релизный канал для всех — опционального раннего доступа к новым фичам лаунчера нет.

## Оптимизация под слабое железо
- Для железа уровня GT710 и ниже лаунчер автоматически предлагает поставить моды оптимизации (типа Sodium/Lithium).
- Автоматически повышает системный приоритет процесса игры для лучшей производительности.
- Встроенный оверлей лаунчера с FPS и загрузкой системы поверх игры.

## Обновления модов/сборок
- Если у установленного мода или сборки вышло обновление — лаунчер уведомляет и даёт обновить одной кнопкой.
- Если обновление сборки сломало игру — доступен откат (rollback) к предыдущему состоянию одной кнопкой. Автобэкап делается перед каждым обновлением сборки автоматически.
- Обновление показывает список изменений: что добавилось/убралось/обновилось.
- Лаунчер не занимается продажей/предложением купить официальный лицензионный аккаунт — это вне его задач.

## Discover (трендовые сборки)
- Раздел с популярными/трендовыми сборками — внутри вкладки сборок, не на главном экране (чтобы не захламлять его).

## Диспетчер загрузок
- Нужен полноценный диспетчер: пауза/возобновление, ограничение скорости, очередь, автоповтор при обрыве, прогресс/ETA по каждому файлу.
- Загрузка нескольких файлов параллельно, для скорости.
- Отображение прогресса контекстное: на странице загрузок — детальный прогресс по каждому файлу; при переходе в другие разделы лаунчера — один общий прогресс-бар внизу (по типу Steam).

## Формат распространения
- И установщик (installer), и портативная версия (без установки).
- Для Linux — несколько форматов упаковки (AppImage, deb и т.д.), не один универсальный.
- Портативная версия хранит настройки в своей папке с программой — можно перекинуть на другой ПК (например, с флешки) со всеми настройками.

## Ники без лицензии
- Конфликты одинаковых ников между безлицензионными игроками на одном сервере решает сам сервер, не лаунчер.

## Импорт/экспорт сборок
- Формат ещё не выбран, но в идеале — поддержка всех распространённых форматов (Modrinth .mrpack, CurseForge и т.д.).
- Версии модов в сборке можно зафиксировать, чтобы они не обновлялись автоматически.

## Импорт из других лаунчеров
- Не требуется (TLauncher, MultiMC и т.д. — без миграции).

## Локализация
- Русский, английский, украинский на старте.

## Тема интерфейса
- Только тёмная тема.
- Возможность смены дизайна (кастомные темы) рассматривается как опциональная, но пока не решено — скорее всего, её не будет. Причина: на текущем этапе интерфейс в стиле Aleph Studio визуально сильно «сливается», но есть прототип того же дизайна, где это не проблема — считается временной проблемой текущей разработки, а не решением на будущее.

## Статистика игры
- Встроенная статистика: часы игры и т.д., в том числе по сборкам.

## Настройка RAM/JVM
- Ручная настройка выделяемой памяти и JVM-аргументов доступна в обоих режимах (упрощённом и профессиональном).
- По умолчанию RAM для сборки подбирается автоматически на основе железа.
- Помимо JVM-аргументов, можно настроить свои аргументы запуска самой игры.
- Рекомендованные JVM-флаги (типа Aikar's flags) не применяются автоматически — доступны только вручную по желанию пользователя.

## Совместная игра / Steam
- Вместо своего хостинга/Open to LAN — интеграция со Steam по аналогии с недавно вышедшим модом: приглашение друзей и совместная игра через Steam.
- По возможности реализуется встроенной функцией лаунчера, а не отдельным модом.
- Доступна всем игрокам независимо от типа аккаунта (лицензия, WetID, свой ник).
- Чата с друзьями в самом лаунчере нет — только внутриигровой чат.
- Отдельно есть кнопка «создать локальный сервер» — запуск собственного выделенного сервера для сборки, не только через Steam-приглашения. Сервер останавливается вместе с закрытием игры/лаунчера (не работает независимо). Помощь с доступом друзьям из интернета (туннелинг/проброс портов) за пределами локальной сети — пока не решено.

## Облачная синхронизация
- В v1.0 не реализуется. Планируется в будущих версиях (через WetID/облако).
- В 2.0 синхронизируется всё, включая сборки и моды, а не только настройки/скины/профиль.
- В v1.0 есть ручной способ: экспорт/импорт всех настроек лаунчера файлом для переноса на другой ПК (без облака).

## Лента новостей
- Пока не решено, нужна ли лента новостей/статей на главном экране.

## Скриншоты
- Встроенная галерея скриншотов из игры.

## Мультиаккаунтность на устройстве
- Можно добавить несколько лицензионных (Microsoft) аккаунтов на одном устройстве.
- WetID — только один аккаунт на человека.

## Диагностика и данные
- Анонимные краш-репорты отправляются автоматически для диагностики проблем, но их можно отключить в настройках.
- При конфликте модов/зависимостей лаунчер не пытается разрешить конфликт автоматически — ошибка просто отображается в логах после краша.
- Автоматического «безопасного режима» при постоянных крашах нет — отключение модов делает сам пользователь вручную.
- Доступность (масштаб шрифта, режим для дальтоников и т.д.) не входит в v1.0.

## Целостность и удаление
- Кнопка «проверить/восстановить файлы» для сборки, если что-то повредилось или пропало.
- Общая оценка состояния сборки («health score»), объединяющая все проверки (целостность, совместимость, конфликты и т.д.) в одну оценку.
- При удалении сборки — не сразу навсегда, а в корзину с возможностью отменить удаление.
- При удалении самого лаунчера — спрашивает, удалить или оставить данные (сборки, миры, настройки).
- Можно сделать полный бэкап целой сборки (моды+настройки+миры) на внешний диск для личного архива — отдельно от шеринга сборок в 2.0.

## Управление мирами (сейвами)
- Бэкап и восстановление миров прямо из лаунчера.
- Бэкап доступен и по расписанию (автоматически), и вручную по кнопке — на выбор пользователя.
- Папку для хранения бэкапов миров можно выбрать самому (например, синхронизируемую папку Dropbox/Google Drive).

## Границы v1.0 (что переносится на 2.0)
- Интеграция с Aleph Guard / режим античита — не в v1.0. В 2.0 появятся проверка целостности, полноценное сканирование устройства и противодействие читам.
  - Сканирование устройства в 2.0 работает на уровне ядра системы (kernel-level), а не только на уровне процессов.
  - Определение читов — и по сигнатурам известных чит-клиентов/инжектов, и поведенческим анализом.
  - Решение о бане/наказании при обнаружении признаков чита принимает сам сервер, а не глобально Aleph Trust/лаунчер.
  - Aleph Guard можно отключить при игре на обычных/не-Aleph серверах.
  - Владельцы серверов подключают Aleph Guard сами через плагин.
  - Для владельцев серверов Aleph Guard/Aleph Trust не бесплатны — модель подписки (месяц/год). Зависит ли цена от размера сервера (числа игроков/слотов) и есть ли бесплатный тариф для маленьких/некоммерческих серверов — пока не решено.
  - Для владельцев серверов будет веб-панель Aleph Trust с аналитикой, банами и управлением подпиской.
  - Апелляция на бан от Aleph Guard и пробный период перед подпиской — пока не решено, будут ли они.
  - Общая база банов по WetID между разными серверами сети — пока не решено, будет ли она.
- Экспорт/шеринг сборки для других пользователей — не нужен в v1.0. В 2.0 реализуется файлом (экспорт/импорт) — ручная передача файла через мессенджер/диск, без прямой отправки другу внутри лаунчера.
- Облачная синхронизация — не в v1.0. В 2.0 синхронизируется всё, включая сборки и моды, а не только настройки/скины/профиль.
- Система друзей через WetID в 2.0: видно, кто из друзей онлайн и на каком сервере. Онлайн/игровой статус всегда виден друзьям, скрыть его нельзя. Способ добавления друзей (по нику/ID или френд-код) пока не решён. Общая кросс-серверная репутация/уровень доверия WetID-аккаунта — пока не решено.
- Идея для 2.0: если в сборке есть локальный (не из Modrinth/CurseForge) мод — по умолчанию вход на сервера Aleph Trust блокируется, если только сервер отдельно не разрешил именно этот мод.

## Система скинов
- Отдельная вкладка: выбор готового скина из подборки или загрузка своего файла — всё бесплатно, без встроенного редактора в v1.0.
- Модерации/фильтрации загружаемых скинов нет — загрузить можно что угодно.
- Цель — покрыть максимальный процент пользователей на максимальном числе серверов, чтобы скины были видны друг другу даже без лицензии. Реализация будет местами «костыльной», но лучше, чем ничего.
- Процент, который не получится закрыть глобально, закроет собственная (лаунчерная) система скинов — её увидят только пользователи AMC Launcher. Это не искусственное ограничение, а следствие отсутствия иного технического способа.
- **Механика без лицензии:** пользователь выбирает скин в лаунчере → при заходе на сервер со скин-плагином (например, через команду вида `/skins <название>`) лаунчер валидирует скин через NameMC и сам отправляет с клиента нужную команду, чтобы сервер поставил скин. Для серверов с другими плагинами/системами скинов будут придумываться отдельные обходные решения — набор костылей ради максимального охвата.

## Аккаунты
На третьем шаге мастера настройки предлагается три варианта:

1. **Официальный лицензионный аккаунт (Microsoft)** — позволяет заходить на лицензионные сервера.
2. **WetID** — опциональный аккаунт экосистемы Aleph Trust. Без входа в WetID недоступен аккаунтный функционал и сервера Aleph Trust. Поддерживает двухфакторную аутентификацию (2FA).
3. **Продолжить без аккаунта** — пользователь сам вписывает ник, под которым заходит в игру, и может изменить его в любой момент.

Логика комбинаций:
- Вход только в WetID → открывается аккаунтный функционал (Aleph Trust сервера и т.д.).
- Вход в WetID + лицензионный аккаунт → при заходе в игру можно выбрать: играть под самостоятельно вписанным ником (без лицензии) или под лицензионным аккаунтом (доступ к лицензионным серверам).
- Лаунчер спрашивает выбор (лицензия / WetID / свой ник) при каждом запуске, но с чекбоксом «запомнить выбор».
- Строго один WetID-аккаунт на человека — привязать несколько WetID к одному устройству/профилю лаунчера (например, для членов семьи) нельзя.
- Каждой сборке можно назначить аккаунт по умолчанию, чтобы не выбирать его при каждом запуске.

## После запуска игры
- Поведение лаунчера настраивается: на слабых ПК можно свернуть его в минимальное состояние с минимальной нагрузкой на систему (только нужные фоновые действия), либо оставить полностью открытым — на выбор пользователя.
- Можно запускать несколько сборок одновременно, включая одну и ту же сборку несколько раз параллельно.
- Распределение RAM между одновременно запущенными сборками настраивается — можно выбрать гибкое (общий лимит) или независимое (у каждой сборки своё) потребление.
- После выхода из игры (не краш) показывается сводка сессии (время игры и т.д.).
